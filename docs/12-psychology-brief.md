# 给心理学组：现在系统实际在做什么

2026-11-08。讨论用的一页说明，不是评测结论。登记表里的阈值、幅度档和初始值都来自心理学组的 v1 文件，**没有标定，不能当成心理学规律**；还没有跑过真实模型，mock 运行只说明流程走得通。字段该怎么交付见 [05-psychology-interface.md](05-psychology-interface.md)。

## 你们的 v1 文件怎么进入代码

四份文件和三个心理流程 skill 生成登记表 `data/registry.json`：87 个构念、75 个决策过程、11 个算子，每项带原文出处。哪个算子能写哪些构念、在哪个阶段写、哪些变化必须一起写、一次能变多少、角色能不能自知，代码都只从登记表读。

## 一个角色的一次行动

场景只给共享背景和座位，没有剧本。轮到谁，谁就把自己还没处理过的记录处理一遍，再决定做什么：

1. **S1 事件建模**（每组记录一次）：情境定义、评价（得失、威胁、挑战）、归因、1–3 个假设及其证据、判断状态、信息需要、关系信号。
2. **S3 长期演化**（上次计划的受众第一次回应时，每个计划一次）：预期与实际的差距、承诺的裁定、关系走向、学习归因、带到以后的东西。
3. **S2 行动计划**：候选、选择、备选、切换条件、承诺、表达目标 / 受众 / 方式。
4. **表达**：思考（只给自己）、发言、动作。

每一步是一次模型调用。模型在登记表允许本阶段调用的决策过程里**只做判断**（选项、本角色的事件等级、方向、对谁），**不写状态**。哪些状态因此变化、往哪个方向，由程序里的更新算子按状态变化规则 §五 的规则卡决定；幅度档按事件等级、人格敏感度和证据质量在选值之前算好；然后模型只在这个区间里选一个具体值并说一句理由（规则 §5.0"模型的选择范围"）。程序再检查证据、权限和区间，越界拒绝不截断，同组的一起不写。规则卡还没实现的算子不写，并在记录里注明。

## 提示里放什么

- 稳定画像按自知程度分层：能自知的模块以内容出现；不能自知的只以条件化语句出现在"说不出来、但会影响你的倾向"里，不带名字和数值。来源没写自知程度的 20 个构念现在按不能自知处理。
- 想隐瞒的事进 S1 / S2 / S3，**不进表达**；表达也看不到状态数值、构念名和其他候选。
- 别人的思考、状态和开场设定从不进入自己的提示。

## 线索、skill、三种模式

- S1 给出五种线索的强度（不确定、压力、承诺、修复、冲突，0–1），**只用来激活人格 skill**，不直接改状态。
- skill（库里 9 个）是写好的应对策略；被激活的至多 3 个进入 S2 和表达的提示，不写状态。内容是工程侧拟的，等审定。
- 三种消融模式用于对照：只给画像；画像 + 动态状态；画像 + 动态状态 + 决策过程判断。状态在三种模式下都照常计算和记录。
