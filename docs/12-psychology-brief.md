# 给心理学组：现在系统实际在做什么

2026-10-20。讨论用的一页说明，不是评测结论。所有系数、阈值、初始值都是工程占位，**没有标定，不能当成心理学规律**。完整待裁定清单见 [plan/06-psychology-decisions.md](../plan/06-psychology-decisions.md)；字段该怎么交付见 [05-psychology-interface.md](05-psychology-interface.md)。

## 一场对话里，一个角色做三件事

场景只给共享背景和座位，没有剧本。轮到谁，谁就对自己刚听到的话做下面三步（本地已用 Qwen3-8B、思考模式跑通两人对话）：

1. **感知评价（模型）。** 站在本人立场看刚听到的话，输出五种线索里感受到的那些，强度 0–1：不确定、压力、承诺、修复、冲突。提示里有本人画像、行为语句、目标、开场设定和可见历史。
2. **状态更新（程序，不靠模型改数字）。** 机制卡里的公式把线索变成状态变化，必须引用这条可见事件。现在真正会改的只有两条：
   - 紧张：`旧紧张 × (1 − 恢复速率) + 0.35 × 压力 × 威胁敏感度`，没有新压力就按恢复速率回落。林澄敏感度 0.9、恢复 0.16；周越是 0.2、0.6。
   - 信任：只有旁白或环境裁决里的兑现 / 失约记录才动，幅度 `0.15 × 信号`。**口头承诺不算兑现**，所以纯对话里信任停在初始值 0.55。
3. **决策，再表达（各一次模型调用）。** 决策从七个交流动作里选一个（要证据、澄清、提方案、划边界、暂缓、同意、结束）。表达只把动作说成台词。想隐瞒的事可以进评价和决策，**不进表达**。

状态以「低 / 中 / 高」进入三次调用（按 0–1 三等分，工程假设）。决策还能看到数值；表达看不到数值和机制名。

## 线索、机制卡、skill 各管什么

| | 是什么 | 现在实际起的作用 |
|---|---|---|
| 五种线索 | 模型对「我听到了什么」的评分 | 只有「压力」改紧张；其余四种只进记忆，并用来选卡、激活 skill |
| 五张机制卡 | 何时倾向哪种应对；其中两张带状态公式 | verify / repair / boundary **没有**状态公式，日志里标明「无状态更新规则」 |
| skill（9 个） | 写好的应对策略（决策要点、表达要点、不会做的事） | 只影响选什么、怎么说，**不写状态**。内容是工程侧拟的，等审定 |

人格档案里启用的是 P1（大五 + NEO 30 分面），只是实现基线，不是已经选定。依恋两轴只存储。71 维、发展位置、荣格功能标为未建模。六个状态域的结构在，但除紧张和对对方的信任外都是未知或未建模。

## 多人和环境

一场可以有 2–6 个角色，按座位轮流发言。可选一个规则驱动的环境（推进时间、改天气、发旁白，旁白可以只给某一个人）。环境不替人说话，也不直接改心理状态。

## 请先裁定的三件事

其余问题在 [plan/06](../plan/06-psychology-decisions.md)。建议讨论顺序：

1. **人格算了两次。** 画像已经让模型按「本人」打线索，公式又乘一次敏感度和恢复速率。线索应该是事件的客观强度，还是本人感受到的强度？人格系数管敏感度、峰值还是恢复？
2. **五种线索够不够，各该改哪个状态。** 不确定、冲突、修复现在不改任何数字。
3. **纯对话里什么可以动信任。** 现在只有可核验的兑现 / 失约。具体说明、前后一致、被识破的回避、道歉加补救，该动「可靠性」，还是只动「对对方意图的推测」？
