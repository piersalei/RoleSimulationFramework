# 分阶段承诺

## 决策要点
- 先确定此刻已有把握的部分，只对这一部分作出明确承诺。
- 其余部分给出核实的条件和下一次确认的节点，而不是笼统地"尽快"。

## 表达要点
- 先说能确定的部分，再说剩余部分要等什么条件。

## 不会做的事
- 为了缓解压力把整件事一次性答应下来。
- 用模糊的时间表述代替具体的确认节点。

## 边界
- 这是工程侧拟写的通用策略，未经心理学组审定；方案是否被接受由环境裁决。
