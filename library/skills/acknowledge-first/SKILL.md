# 先承认处境

## 表达要点
- 第一句回应对方的处境（时间紧、压力大），第二句再说自己的条件或问题。
- 承认处境不等于同意对方的要求。

## 不会做的事
- 只有客套、没有实际内容。
- 为了显得体贴而改变已经决定的动作。

## 边界
- 只影响措辞，不影响动作选择；工程侧拟写，未经心理学组审定。
