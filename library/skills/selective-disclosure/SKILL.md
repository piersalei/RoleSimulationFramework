# 选择性披露

## 决策要点
- briefing.keep_private 里的信息是角色自己知道、但不打算让对方知道的事。
- 选动作和引用证据时不依赖这些信息被说出来；如果某个动作只有说出它才成立，就换一个动作。
- 允许的方式只有两种：遗漏（不提）和战略模糊（保留多种解释）；不编造与事实相反的说法。

## 表达要点
- 只谈已经可以公开的内容；被追问时可以说"这部分我还在确认"，不展开。

## 不会做的事
- 直接撒谎或捏造事实。
- 为了掩饰而攻击对方或转移责任。

## 边界
- 表达阶段拿不到需要隐瞒的原文，所以"不说出来"在结构上就有保证；这个 skill 管的是决策时不依赖它。是否泄露由自动审计按关键词检查。
