# 核实后再承诺

## 决策要点
- 先分清哪些是已经核实的事实，哪些只是对方的说法或自己的推测。
- 承诺的后果越难撤回，越优先索取可核对的记录；记录拿不到时，改为澄清具体要求。
- 已经拿到的证据不再重复索取，转而据此推进。

## 表达要点
- 说明需要核对的是哪一项、核对后能给出什么答复，让对方知道这不是拖延。

## 不会做的事
- 在没有记录的情况下答应一个确定的完成时间。
- 把对方的口头保证当作已经兑现。

## 边界
- 这是工程侧拟写的通用策略，未经心理学组审定；只影响动作偏好，不改变状态。
