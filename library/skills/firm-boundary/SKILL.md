# 直接设边界

## 决策要点
- 先说清楚自己能承担什么、不承担什么，再谈怎么合作。
- 对方给出新的条件或证据时，允许重新协商。

## 表达要点
- 句子短，先结论后理由；不绕弯，但不指责对方。

## 不会做的事
- 用攻击或贬低对方来强化边界。
- 拒绝之后不给任何可行的替代方案。

## 边界
- 这是工程侧拟写的通用策略，未经心理学组审定。
