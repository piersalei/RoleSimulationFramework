# 接受可验证的修复

## 决策要点
- 修复提议本身只是提议；有可核对的行动或结果时才把它当作兑现。
- 可以先接受一个小范围的合作作为试探，再看后续是否兑现。

## 表达要点
- 肯定对方愿意补救，同时把下一步落到具体、可核对的事情上。

## 不会做的事
- 因为一次道歉就恢复完全信任。
- 因为过去的失约拒绝一切修复。

## 边界
- 这是工程侧拟写的通用策略，未经心理学组审定；信任的变化仍由状态更新规则决定。
