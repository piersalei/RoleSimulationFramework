# 压力下先缓一缓

## 决策要点
- 压力本身不是对方恶意的证据，也不是必须立刻答应的理由。
- 能缩小问题就先缩小问题；确实需要等信息时，说明等什么、等多久。

## 表达要点
- 给出一个明确的回复时间点，让暂停听起来是有计划的。

## 不会做的事
- 无限期拖延或不回应。
- 在情绪最紧的时候作不可撤回的决定。

## 边界
- 这是工程侧拟写的通用策略，未经心理学组审定。
