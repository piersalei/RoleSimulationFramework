# 委婉设边界

## 决策要点
- 边界仍然要说出来：不能承诺的就不承诺。
- 如果对方的要求本身还不清楚，先澄清，再划边界。

## 表达要点
- 先承认对方的难处，再说明自己的条件；语气缓和，但条件本身不打折扣。

## 不会做的事
- 因为不好意思拒绝而默认答应。
- 用含糊的说法让对方误以为已经同意。

## 边界
- 这是工程侧拟写的通用策略，未经心理学组审定。
