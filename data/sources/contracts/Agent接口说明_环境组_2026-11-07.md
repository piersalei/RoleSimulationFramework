# Agent 接口说明

本文只说明 Agent 组需要实现的三个接口：角色初始化、角色行动和环境行动。

导演调度、互动环境维护、行动校验、接收范围解析、`ActionRecord` / `InteractionRecord` 生成、观察记录保存和三级能力标注不属于 Agent 组接口。

## 1. 角色初始化接口

### 功能

在一条具体互动轨迹开始时，为每个角色建立对应的 Agent 运行上下文。环境会遍历本次互动的全部角色，每个角色只调用一次初始化接口。

Agent 侧使用 `interaction_id + character_id` 作为路由键，自己保存或管理该角色在该互动中的会话状态。环境不保存 Agent 对象，也不要求返回 Agent ID。

### 接口

```python
class AgentAdapter:
    async def initialize(
        self,
        interaction_id: str,
        character_id: str,
        bootstrap: CharacterBootstrap,
    ) -> None:
        ...
```

### 输入：`CharacterBootstrap`

```python
CharacterBootstrap = {
    "setting": {
        "place": str | None,             # 当前互动地点
        "time_text": str | None,         # 当前互动时间表达
    },
    "trigger_facts": list[str],          # 所有角色共同知道的公开触发事实
    "name": str,                         # 当前角色姓名
    "profile_summary": str,              # 当前角色的稳定人物总结
    "core_goals": str | None,            # 本次互动全过程不变的总体目标
    "relationships": list[str],          # 当前角色与其他角色的关系句
    "history_memory": str | None,        # 当前角色在互动前实际经历或获知的内容
    "personality": dict,                 # 当前分支指定的人格配置
    "mechanism": dict,                    # 当前分支指定的行动机制配置
}
```

字段均来自互动环境中的当前角色资料和故事入口。`CharacterBootstrap` 不包含其他角色的私有认知、其他角色的观察记录或完整互动历史。

### 输出

```python
None
```

初始化成功只表示 Agent 已完成该 `interaction_id + character_id` 的准备，不返回业务数据。

## 2. 角色行动接口

### 功能

根据角色初始化时获得的固定资料、本轮传入的可见观察记录和当前在场角色，生成该角色的一次行动。一次调用可以同时返回思考、发言和外显行动，由 `order` 指定三者的发生顺序。

环境只调用当前 `present_characters` 中的角色。角色不能通过该接口修改其他角色、在场范围、观察记录或互动环境状态。

### 接口

```python
class AgentAdapter:
    async def act(
        self,
        interaction_id: str,
        character_id: str,
        context: CharacterTurnInput,
        request_id: str,
    ) -> AgentActionResult:
        ...
```

`interaction_id + character_id` 用于将行动请求路由到初始化时对应的角色 Agent。

### 输入：`CharacterTurnInput`

```python
CharacterTurnInput = {
    "bootstrap": None,                    # 初始化资料已由initialize发送
    "observations": list[InteractionRecord],
                                           # 当前角色已经看到的全部单条记录
    "present_characters": {
        "<character_id>": {"name": str},
    },                                     # 当前在场、可作为接收者的角色
}
```

后续行动调用只传入 `CharacterTurnInput`。Agent 可以使用自己在初始化阶段保存的资料，以及本字段中的 `observations` 和 `present_characters`；环境不会额外传入完整 `InteractionEnvironment`、`story_background`、其他角色信息或全局互动历史。

`observations` 中每条记录已经由环境按角色可见范围筛选，并按实际发生顺序展开：

```python
InteractionRecord = {
    "action_id": str,                     # 同一次复合行动拆出的记录共享
    "turn_index": int,                   # 互动轮次
    "order_index": int,                  # 本轮内部发生顺序，从0开始
    "actor": {
        "actor_id": str,                 # 行动者ID；环境行动者为"environment"
        "name": str,                     # 行动者姓名；环境行动者为“环境”
    },
    "kind": Literal["thought", "speech", "action"],
    "content": str,                      # 该条思考、发言或行动内容
    "recipients": {
        "<character_id>": {"name": str},
    },                                    # 该条记录的明确接收者
}
```

### 输出：`AgentActionResult`

`AgentActionResult` 是 `AgentActionContent` 的语义别名，不增加包装层或额外字段：

```python
AgentActionResult = AgentActionContent

AgentActionContent = {
    "thought": ActionPart | None,         # 思考，可以为空
    "speech": ActionPart | None,          # 发言，可以为空
    "action": ActionPart | None,          # 一句话描述外显行动，可以为空
    "order": list[Literal[
        "thought", "speech", "action"
    ]],                                    # 非空部分的实际发生顺序
}
```

`ActionPart` 结构：

```python
ActionPart = {
    "content": str,                      # 本部分的自然语言内容
    "recipient_ids": list[str] | None,   # 本部分的可见范围
}
```

返回规则：

- `thought`、`speech`、`action` 至少有一个非空。
- `order` 只列出非空部分，每种类型最多出现一次；可以返回 `thought + action` 而不返回 `speech`。
- `speech=None` 合法，例如 `order=["thought", "action"]`。
- `recipient_ids=None` 表示当前 `present_characters` 中的角色都能接收该部分；定向接收者必须使用 `present_characters` 中的 `character_id`。
- 若思考只应被行动者自己看到，应返回只包含行动者 ID 的 `recipient_ids`，不要使用 `None`。
- Agent 不生成 `action_id`、`turn_index`，不返回 `ActionRecord`，也不返回认知字段。系统会在接收后补齐内部记录并按 `order` 拆分。

## 3. 环境行动接口

### 功能

根据当前故事条件、在场角色和导演给出的环境指导，生成一轮客观环境反应，例如广播、电话、声音、门被推开或文件掉落。

环境 Agent 也按 `interaction_id` 路由；它是本次互动中的特殊行动者，路由键可表示为 `interaction_id + "environment"`。环境 Agent 不负责维护在场范围，不能直接修改互动环境。

### 接口

```python
class EnvironmentAdapter:
    async def act(
        self,
        interaction_id: str,
        context: EnvironmentActorView,
        request_id: str,
    ) -> AgentActionContent:
        ...
```

### 输入：`EnvironmentActorView`

```python
EnvironmentActorView = {
    "setting": {
        "place": str | None,             # 当前互动地点
        "time_text": str | None,         # 当前互动时间表达
    },
    "story_background": str,             # 互动开始前的全局故事背景
    "trigger_facts": list[str],          # 已成立的公开触发事实
    "present_characters": {
        "<character_id>": {"name": str},
    },                                    # 当前在场、可接收环境信息的角色
    "environment_directive": str,        # 导演要求本轮环境产生的反应
}
```

环境视角不接收 `interaction_history`、完整 `characters`、人物档案、关系、人格、行动机制或角色私有观察。环境需要定向发送信息时，只能把 `present_characters` 中的角色 ID 放入 `recipient_ids`。

### 输出：`AgentActionContent`

环境使用与角色行动相同的 `AgentActionContent` 和 `ActionPart` 结构：

```python
AgentActionContent = {
    "thought": ActionPart | None,
    "speech": ActionPart | None,
    "action": ActionPart | None,
    "order": list[Literal["thought", "speech", "action"]],
}
```

返回规则：

- 至少返回一个非空的 `thought`、`speech` 或 `action`。
- `order` 只列出非空部分，并按实际发生顺序排列。
- `recipient_ids=None` 表示当前 `present_characters` 中的角色都接收该部分；显式接收者必须来自在场名单。
- 不返回 `action_id`、`turn_index`、`ActionRecord` 或其他环境状态字段。
- 环境的返回结果由运行器统一校验、按 `order` 拆分并写入互动历史；环境 Agent 不直接保存或修改历史。
