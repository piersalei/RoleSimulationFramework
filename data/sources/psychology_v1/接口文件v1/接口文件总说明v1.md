## 一、文件组成

接口文件共三份，定义角色心智状态“是什么、怎样保存、怎样变化”。心智建模库和决策机制库已在前期提供。

| 文件           | 回答的问题           | 地位       |
| ------------ | --------------- | -------- |
| [[心理构念登记v1]] | 每个心理构念在心理学上是什么  | 唯一语义来源   |
| [[角色状态说明v1]] | 角色状态怎样保存、取值和初始化 | 登记表的保存投影 |
| [[状态变化规则v1]] | 什么情况下状态怎样变化     | 登记表的更新投影 |

三份文件用 construct_id 互相对齐，格式为“层前缀.模块.构念”。s 表示 stable，d 表示 dynamic，m 表示 memory，dm 表示决策过程。后两份文件不新增心理含义。三份文件之间有冲突时，定义以登记表为准，保存方式以角色状态说明为准，更新规则以状态变化规则为准。

## 二、各文件主要内容

**[[心理构念登记v1]]**
- 第二、三部分规定条目格式和通用约定：编码锚点、状态标记（active、unknown、inactive、disabled、not_modeled、not_applicable，default 只是来源标记）、能力与倾向等四类对象的区分、证据边界三层。
- 第四部分登记 42 条 stable 构念，分为身份、三套互斥的人格方案、依恋、动力、情感能力、71 维社会心智能力、认知风格、发展位置与自我系统、人格功能、决策偏好、价值、核心目标、表达基线。其中 4.10 给出决策偏好的先验映射权重表。
- 第五、六部分登记 42 条 dynamic 构念和 3 条 memory 构念。dynamic 分为情绪、认知、目标、关系、群体、策略六个状态域。
- 第七部分登记 75 个决策过程及其可选项，第八部分列出候选与暂缓构念，附录列出 71 维三级条目。

**[[角色状态说明v1]]**
- 第二部分列出依赖环境组的假设，相关位置标有【待环境组确认】。
- 第三部分是通用规则：取值形式、外部量表的换算、空值处理和元数据。
- 第四至六部分逐模块写出保存结构、必填与空值、可见性。
- 第七部分规定三层可见性和角色输入的边界。
- 第八部分规定初始化：来源类型、随机抽样先验、入场默认值、心理理论层级判据、需审核的高影响字段、装配顺序和发展位置的人群先验。
- 第九、十部分规定启用配置和版本兼容，附录给出王伯的最小初始状态示例。

**[[状态变化规则v1]]**
- 第二、三部分是分层原则和运行总则。决策过程只产生判断，没有写权限，只有 11 个更新算子可以写回。运行总则包括可见证据集、共同快照、七步事件处理顺序和四级事件等级。
- 第四部分给出决策过程到算子的映射和高影响过程的机制卡。
- 第五部分是 11 张算子规则卡，并规定幅度分档。
- 第六至九部分规定合并与原子提交、幅度生成和人格调节、硬错与软异常、各字段半衰期。
- 第十至十三部分规定 stable 长期变化的门槛、StateDelta 与 mechanism_log 的记录要求、覆盖矩阵和后续版本候选算子。
