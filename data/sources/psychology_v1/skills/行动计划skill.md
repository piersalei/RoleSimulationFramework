## 0. 定位与边界

### 0.1 目标

角色拿到情境解释后，要决定现在怎么做。这个决定不是在“目标、关系、规范”三者之间挑一个，而是在多重目标、身份与角色义务、价值和规范、资源与能力限制、风险、情绪、自我形象、群体位置、信息不确定性和不同时间尺度之间找出一个可执行的方案。本 skill 要分开回答五个问题：这次行动服务什么，能做哪些，哪些不能做，各个方案保护了什么、牺牲了什么，现在先做什么、情况变了改做什么。

### 0.2 负责范围

本 skill 覆盖从情境解释到外显行动的全过程。它先确定决策框架和互动结构，生成候选行动，用硬约束筛掉不具备执行条件的方案；再逐个估计方案在不同维度上的后果，处理价值、目标和规范之间的冲突以及信息上的不确定；然后选定主行动和备选计划，写明切换条件，判断是否形成承诺，最后决定表达方式并向互动环境输出行动。过程中产生的当前目标、承诺、策略、自我状态和群体状态变化，以候选状态变化的形式提交。

### 0.3 不负责范围

本 skill 不重新解释事件。情境解释需要修订时，交回事件建模skill在新阶段处理，本 skill 只读取修订后的结果。它不判定行动是否成功，不根据行动结果更新关系、信任、声誉和策略权重，不认定承诺已兑现或已违约，也不巩固事件记忆，这些归长期演化skill。它不改写 core_goals、稳定价值、人格和角色身份，不触及任何 stable 字段。

### 0.4 与前后 skill 的接口

上游输入是事件建模skill输出并已完成校验提交的情境解释，加上最新已提交的 dynamic、相关 memory 和上一阶段的行动计划。情境解释里的他心假设、预测和判断状态都是候选，不是事实。

下游方面，选定的行动发送给互动环境。本 skill 设定的观察信号交给事件建模skill，环境和他人的反馈先由它解释，再回到本 skill 修订计划。选定行动、预期结果、所形成的承诺，连同事件建模已经交出的关系信号和承诺信号，一起交给长期演化skill，由它在获得反馈后判断关系、承诺和策略是否写回。

## 1. 触发条件

### 1.1 选择触发

事件建模skill 的情境解释提交后，下列情形触发本 skill：存在两个或以上可行行动，等待也算一种行动；当前目标、长期目标、角色义务、群体规范或关系利益之间发生冲突；某个可行行动具有风险、不可逆性、公开性，或会带来未来承诺。

### 1.2 计划修订触发

已有计划在下列情形下进入修订：新信息使原计划的前提不再成立；上一阶段写明的切换条件出现；未完成承诺的期限临近或执行条件改变；行动反馈到达。反馈必须先经事件建模解释，本 skill 读取的是角色对反馈的理解，而不是系统掌握的真实结果。修订以上一阶段的计划为起点，改与不改都要说明理由，不从头重新抽取一套策略。

### 1.3 简化处理与不触发

熟悉、低风险且只有一个合理选项的情境，可以直接沿用习惯或默认脚本，不展开完整权衡，但要记录本次由习惯路径主导。情境解释判定事件与角色的目标、关系、规范和自我都无关时，不触发本 skill。角色不可见的事件从不触发本 skill。

## 2. 输入与读取来源

### 2.1 情境解释与场景上下文

情境解释提供角色采信的证据、情境定义与规范违背判断、初级与次级评价、归因与责任判断、他心假设集合及置信度、判断状态、信息需求和行动线索。行动线索只是候选行动的起点，既不是完整的选项集，也不是已作出的选择。仍处于保留状态的多个假设都要进入后续权衡：计划要么在这些假设下都站得住，要么包含能区分它们的信息搜集步骤。

场景上下文提供角色当前可用的行动渠道、在场者与受众、公开程度、适用的制度规则、时间限制和他人的可见行为。角色不可见的信息在这里同样被排除。

### 2.2 stable

identity 决定行动空间。职业、职位和资源可得性限定角色能承担的风险和可选方案，其中制度权力、公共声望和专业权威要分开读取，它们支持的影响方式不同。社会角色提供角色义务、角色权利和角色显著性；多个角色提出不相容要求时，冲突保留到权衡环节，不用一个主角色抹去其余身份。可观察资源和沟通媒介限定角色能用什么方式行动，以及他人能看到什么。角色认同中的身份标准和显著性，决定哪些行为被角色认为“符合这个身份”。

traits 中，主人格改变角色的敏感度、阈值和表达倾向，不规定具体动作；分面冲突时写成有条件的组合，例如在任务责任上主动主张、在关系冲突上愿意让步。动力系统提供目标计算所需的基线：BAS、BIS 与 FFFS 的敏感度，促进焦点与预防焦点，接近与回避方向，期望、价值与成本的权重，目标层级参数和稳定冲突主题。71 维社会心智能力给出执行上限，例如谈判、表达和预测他人反应能做到什么程度；能力高不等于本次一定调用。认知风格中的闭合需要和模糊容忍，影响角色何时停止搜索、是否接受临时方案。成人依恋影响求助和接近方式。

values 提供十九项价值的相对优先级，以及每项价值的冲突阈值和可让步范围。道德推理阶段决定角色如何组织行动理由，文化取向决定角色对权力距离、群体义务等场景要求的默认反应。价值、规范、目标和人格要分开读取：价值说明什么结果值得追求，规范说明此情境中什么被期待或被制裁，目标是此刻要实现的具体结果。

core_goals 是当前目标的上位链接，说明一次行动最终服务于哪个长期结果。speech_style 提供表达基线，本次因情绪、关系和权力差产生的表达调整，要与基线分开记录。

### 2.3 dynamic

goal_state 中的当前目标、优先级、承诺度、可行性、冲突关系和行动指向，是决策框架的直接依据。

affect_state 中的情绪、唤醒、压力和威胁或奖赏激活，影响时间折扣、风险偏好、能否进入审慎比较，以及是否需要先暂停。

cognition_state 提供已提交的事实信念、对他人的推断、自我评价和可控性感知。

relation_state 中的信任、亲近、依赖、承诺、权力差和伤害历史，用于预测对方反应和选择表达方式；权力差要区分客观方向、角色主观感知和信息可见性。它在本 skill 中只被读取，不被修改。

group_state 中的成员资格、身份显著性、规范显著性、联盟和责任分配，决定行动在群体中的意义和代价。

policy_state 提供尚未完成的承诺、当前策略、备选方案、切换条件和反馈权重；没有切换条件被满足时，上一阶段的策略保持默认地位。

### 2.4 memory、thought 与 mechanism_log

memory 检索与当前对象和相似情境有关的经验：过去用过什么策略、结果如何、对方怎样回应、角色作过哪些承诺。mechanism_log 提供上一阶段的选择理由、未选方案、预期结果、观察指标和切换条件，用来对照当前情况，判断是继续、调整还是切换。thought 是模型的原始输出，不作为决策依据。

### 2.5 读取快照与优先级

本 skill 读取事件建模候选变化提交之后的最新快照，同一角色、同一事件、同一阶段只读这一份。内部各步骤之间传递的判断都是候选，不是已生效的状态。

读取时，硬约束先于偏好：安全、制度、能力、权限和明确承诺先限定可行范围，人格和价值偏好只在可行范围内起作用。涉及特定对象时，对象特异的关系史优先于全局依恋基线。某个模块处于未知、关闭或未建模状态时，跳过依赖它的权衡分支，记为信息不足，也不在行动表达中假装这一模块已被建模。

## 3. 处理流程

### 3.1 确定决策框架

先明确这次行动服务哪些当前目标，它们分别链接到哪个核心目标，受影响的对象有谁，时间范围覆盖即时、本阶段还是长期，行动是否公开、谁会看到，是否可逆，以及哪些风险角色无论如何不接受。同时判断当前被激活的是哪项角色身份，它带来哪些义务和权限。

接着识别互动结构：协调、互补合作、竞争、讨价还价、重复互动或不完全信息。结构判断保留确信度和替代结构，事件推进中发现结构判断有误时重新评价。最后根据信息完整度、时间、风险、目标涉入和认知资源，确定本次由哪种选择规则主导：期望效用、前景理论、满意化、启发式或习惯，并记录主导的是习惯路径还是目标导向路径。

### 3.2 生成候选行动

候选行动至少覆盖几种不同类型：直接行动、澄清或搜集信息、合作或求助、有限试探、拒绝或设边界、等待或降温、转交第三方、退出。每个候选都要写明对象、时机、表达方式、投入的资源和预期后果。候选可以是一个行动序列，例如先私下询问、视回应再决定是否设期限。

候选的来源包括情境解释给出的行动线索、policy_state 中已有的策略、memory 中的成功或失败经验，以及角色身份对应的常规做法。探索与利用的权衡决定是否纳入角色不熟悉的方案：不确定性高、资源充足或机会窗口出现时更可能探索，试错成本高、时间紧或已有方案可靠时更倾向沿用。满意化的角色在找到达到最低可接受标准的方案后可以停止搜索，但要记录停止原因。只要情境解释中还有多个假设未被排除，候选集里至少要有一个在主导假设出错时仍然合理的方案。

### 3.3 硬约束筛选

逐项检查安全、法律与制度、能力、资源、角色权限、明确承诺和不可逾越的个人边界。资源包括时间、金钱、信息和可调用的社会支持；个人边界来自价值的最低不可退让点。不具备执行条件的方案，不能只因动机强烈而被选中。依赖角色不可见信息的方案同样不可行，例如拿自己并不知道的内容去质问对方。

被筛掉的方案要保留，并写明是哪一项约束使它不可行。角色因结构性风险或资源不足而没有采取某个行动时，记录的是未行动的约束来源，而不是把它解释为角色缺乏责任感或亲社会性。

### 3.4 评估多维后果

对通过筛选的每个方案，分别估计它在以下维度上的后果：各个目标的进展、关系与依赖、群体规范与声誉、身份与自我一致性、情绪与面子代价、资源和执行成本、信息价值、未来选择空间、升级或失控的风险，以及对下一事件的影响。同一方案可以在一个维度上有利、在另一个维度上不利，各维度分开记录。

估计时，期望、价值和成本分开考虑：高度重视但几乎不可达的结果只产生愿望，容易达成但无价值的结果也不会形成强承诺。风险和模糊分开处理，概率可估计的不确定与概率本身不清楚的不确定对应不同态度。延迟结果按角色的时间折扣计入，同时区分“未来价值低”与“当前资源匮乏”。涉及收益分配时，按角色的社会价值取向和公平规则比较自己与他人的结果。行动意图的强度由对结果的评价、重要他人的期待和知觉行为控制共同形成。

对他人反应的预测，只能使用情境解释给出的他心假设，推断阶数不超过事件建模确定的本次可用层级。预测按假设分别写出，例如在对方遇到外部阻碍和对方不重视任务两种情况下，同一句话会引起什么不同反应。

### 3.5 处理价值、目标与规范冲突

方案之间的取舍，依据角色的价值优先级、冲突阈值和可让步范围，目标层级，风险阈值，时间折扣，关系阶段和策略偏好。目标冲突先看层级：下位手段受阻时可以更换手段而保留上位目标；两个上位目标真正冲突时，才需要价值取舍。价值冲突要写明涉入的价值、相对优先级、最低不可退让点、可接受的补偿和身份关联。当前目标与核心目标冲突时，比较安全与能力边界、价值底线、现实成本和关系义务，记录暂停、换方案或让步的理由。

人际冲突中，冲突处理模式提供当前姿态：竞争、合作、妥协、回避或迁就，取决于目标重要性、关系重要性、时间压力、权力差和未来互动。方案还要评估是否会推动冲突升级，升级体现为行动不可逆性、受众扩大、负面归因和替代选项减少的累积。存在权力差时，角色根据自己的制度位置、资源和合法性选择说服、咨询、交换、施压或授权，处于弱势时考虑公开发声、私下抵抗、结盟或退出等方式。

规范方面，区分“大家实际怎么做”和“大家认为应该怎么做”，看哪一种在当前注意中显著。角色意识到行动或不行动的后果、认为自己有责任和能力介入时，个人规范才被激活。群体压力存在时，区分为了准确而跟随、为了被接纳而公开跟随和公开服从私下保留。涉及他人需要时，按需要识别、责任归因、成本与安全评估的顺序决定帮助、有限帮助、转介或拒绝；涉及自身过失时，区分主动承担、部分承担、解释情境和责任转移。

多个机制同时激活时，各自对方案的支持和反对保留来源。安全门槛和不可逆行动条件优先于普通权重；最高权重项通常主导，只有权重接近的方案之间才使用受限随机或默认策略，不能用随机性制造与核心价值、能力和关系历史相反的行为。

### 3.6 处理不确定性与当下状态

当关键假设尚未区分、错误代价又高时，信息搜集、低成本试探或暂缓本身可以是最优行动。闭合需要高、模糊容忍低的角色倾向于过早选定方案；闭合需要低而错误代价高的角色可能长期不行动。两种倾向都要能在角色设定中找到依据。选择临时方案时，同时写明仍未确定什么和为什么先这样做。

角色的当下状态会改变选择。高唤醒或高压力下，面对不可逆行动时可以先暂停，稳定状态后再决定。情绪调节可以体现为行动本身，例如避开某个场合、改变谈话的人或规则，也可以体现为表达上的克制；每种调节都要估计短期收益和长期代价。即时冲动和延迟目标冲突时，按角色的自我控制方式处理，适应性的控制也包括修改目标、求助和移除诱因。

### 3.7 确定主行动与备选计划

选定主行动后，记录选择理由、放弃其他方案的主要代价、预期结果、观察指标和切换条件。备选计划写明在什么情况下启用。切换条件要落到角色可以观察到的信号上，写成“如果出现某种线索，就改做什么”的形式，而不是笼统的“情况变差就改变”。

要区分三件事：角色打算做什么，角色已经做了什么，结果是否如预期。本阶段只产生第一件；后两件要等行动发出和反馈到达。计划被打断后能否恢复、计划是否已经不适用却仍被坚持，都要在后续阶段对照这里的记录来判断。

### 3.8 决定是否形成承诺

只有角色明确向他人或自己承担未来行动义务，并写明内容、期限或验证条件时，才生成行动承诺。普通的意图、当下的选择、对结果的预测、提议和询问，都不自动成为承诺；提议被对方接受并说定之后，才进入承诺。

形成承诺前，要考虑承诺内容、对象、期限、可验证结果、履行能力和违约后果。公开承诺的声誉价值和违约成本通常高于私下承诺，也更容易因面子压力被过度坚持；私下承诺更易修正，但对群体协调的约束较弱。面子成本高而修复能力低的角色容易过度承诺，这种倾向可以出现，但要能从角色设定中解释。

对已有的未完成承诺，本 skill 决定维持、调整范围、提前预警、暂停或撤销。承诺是否兑现或违约，由长期演化skill在获得结果后认定。

### 3.9 表达方式与行动输出

先确定表达目标和受众，再选择表达方式。直接性取决于关系距离、权力差、强加程度、误解成本、面子威胁和安全风险：误解成本高、任务紧迫时更直接，面子威胁高或需要给对方留退路时更间接。请求、批评、纠正和要求承诺都会威胁对方的面子，角色可以用认可和亲近降低关系威胁，也可以用给选择、降低强加来维护对方的自主。设边界时，说明自己愿意做什么、不能接受什么、继续发生会怎样，而不是规定对方必须怎样想。选择性呈现、隐瞒或误导只能在角色的价值和道德约束内出现，并计入被识破的风险和关系代价。

表达在 speech_style 基线上调节，本次的调节方向和原因单独记录。执行时分三层记录：角色想达成什么，实际说了或做了什么，对方能看到什么。最终向互动环境输出一个可执行的行动、言语行为或等待指令。等待也要写明何时重新评估，避免被对方体验为惩罚性冷处理。

## 4. 调用机制与更新算子

### 4.1 决策机制

本 skill 调用的机制来自决策机制库的八个部分。信息加工部分提供有限理性与满意化（1.4）、不确定性与闭合需要（1.5）。评价与调节部分提供情绪调节（2.3）、应对方式（2.4）和自我控制（2.6）。学习部分提供探索与利用（4.3）、习惯与目标导向行动（4.6），在本 skill 中只读取已有的策略权重和习惯强度，不做学习更新。选择部分提供选择规则（5.1）、风险与模糊（5.2）、时间折扣（5.3）、社会价值取向（5.4）、公平规则（5.5）、意图形成（5.6）和实施意图（5.7）。沟通部分提供直接性（6.1）、面子管理（6.2）、对话修复与承诺管理（6.4）、印象管理（6.6）、隐瞒与操纵（6.7）和断言与边界（6.8）。合作部分提供互动结构识别（7.1）、谈判（7.5）和信号、承诺与声誉（7.6）。冲突部分提供冲突处理模式（8.1）、升级与降级（8.2）、权力行使与抵抗（8.4）。社会结构与亲社会部分提供角色与权威服从（9.4）、从众（9.6）、规范焦点（9.10）、规范激活（9.12）、帮助与照护（10.1）和责任承担与转移（10.2）。

机制组合遵循各章的组合规则：先识别结果结构、关系对象和时间范围，再由目标与价值激活确定权重，最后选择计算规则，不同规则得出的冲突结果保留为机制竞争，不强行平均；沟通先定表达目标和受众，再选具体方式；合作各模块分别保存状态，不用一个合作分数代替；冲突中保留竞争权重和最终选择理由，严重功能受损、低共情或高敌对特质只改变概率和代价，不自动推出暴力、操纵或断裂；未行动要记录约束来源。所有机制只产生中间判断、候选行动和未选原因，没有状态写权限。

### 4.2 更新算子

本 skill 的核心写回由三个算子完成。`goal_update` 写入当前目标的激活、切换、降级或暂停，记录它们与核心目标的对应关系，以及冲突时暂停、换方案或让步的理由；它不能为了解释一次行动而改写核心目标。`commitment_update` 写入角色主动作出的承诺决定：形成、维持、调整、暂停或撤销。`strategy_learning` 把当前主策略、备选方案和切换条件写入 policy_state；根据反馈调整策略权重和学习历史，归长期演化skill。

决策改变了角色对当前任务的自我效能、预期的面子代价或对责任的接受时，追加调用 `self_state_update`；决策激活了规范显著性、改变了责任分配或联盟立场时，追加调用 `group_state_update`；本次决策调用了过去的策略经验时，用 `memory_update` 记录检索标记和再激活，事件记忆的巩固不在这里完成。本阶段的情绪调节确实改变了情绪时，结果经 `emotion_update` 写回。

本 skill 不调用 `relation_update`、`belief_revision`、`other_model_update` 和 `decay_or_recovery`。对结果的预测写入日志和策略状态，不作为信念写回；需要修订信念或他人模型时，交回事件建模在新阶段处理。关系、声誉和目标的实际变化，要由相应算子根据行动结果提交，不能仅凭选择意向写回。

### 4.3 执行顺序、候选 StateDelta 与提交

逻辑顺序为决策框架、候选生成、硬约束筛选、后果评估、冲突与不确定性处理、主行动与备选、承诺判断、表达与输出。这是保证可复现的计算顺序，不意味着心理过程是线性流水线。过程中出现新证据时，开启新的事件阶段，先交事件建模解释，不在本阶段内修改已读入的情境解释。

所有候选变化都以同一份快照为前提。由同一个选择产生的目标切换、承诺和策略记录相互依赖，应放在同一个依赖组内提交：其中一项因硬错被拒绝时，整组不生效，对应行动也不按原样发出，在新阶段重新规划。行动竞争中的权重不能替代字段写权限。目标优先级等变化的幅度，要与事件严重度和角色敏感度相称；人格影响的是阈值、敏感度和偏好，不直接放大变化量。

### 4.4 mechanism_log 记录

日志要让一次行动能够回溯到当时的理由。它应记录：决策框架和互动结构判断；主导的选择规则，以及习惯路径还是目标导向路径占主导；全部候选行动，包括被硬约束筛掉的方案和约束来源；各方案在不同维度上的后果估计；各机制对方案的支持与反对；价值冲突的涉入价值、底线和补偿；计划所依赖的他心假设，以及计划在其他假设下是否仍然合理；主行动的理由和放弃其他方案的主要代价；预期结果、观察指标和切换条件；承诺判断及其理由；表达选择和三层执行记录；使用了受限随机时的候选权重和抽样原因；以及候选与最终状态变化、被拒绝的项目和异常标记。这些理由必须在行动发出前写定。

## 5. 输出与接口

### 5.1 行动计划

输出一个行动计划，内容包括决策框架、候选行动集和硬约束筛选结果、各方案的多维后果估计、主行动（对象、时机、表达方式、投入资源）、备选计划、切换条件、预期结果与不确定性、计划所依赖的假设、是否形成承诺，以及需要等待的反馈。计划中的预期结果都是预测，不是结果。

### 5.2 外显行动

向互动环境输出一个可执行的行动、言语行为或等待指令，并附带三层记录：角色想达成什么，实际做了什么，对方能看到什么。

### 5.3 状态变化候选

候选状态变化包括当前目标的变化、承诺的形成或调整、当前策略与切换条件，以及在相应条件下的自我状态、群体状态、记忆检索标记和情绪调节结果。每条候选变化都要引用它所依据的情境解释和选择理由，说明调用了哪些决策机制，经哪个更新算子写回。

### 5.4 交给下一阶段的内容与条件

本 skill 设定的观察信号交给事件建模skill。反馈到达或观察信号出现时，事件建模在新阶段先解释，本 skill 再据此修订计划。

选定行动、预期结果、所形成的承诺和计划所依赖的假设，交给长期演化skill。它在获得反馈后，用预期结果与实际结果的差距判断策略权重是否调整，并认定承诺兑现或违约、决定关系和记忆是否更新。

备选计划、切换条件和尚待的反馈留给本 skill 的下一阶段，作为修订的起点。

## 6. 约束与异常处理

### 6.1 证据与能力边界

角色只能依据自己可见的信息行动，不能使用被排除的内容，也不能把情境解释中可能性最高的假设当作事实来行动。候选行动必须与角色的能力、信息可得性、权力位置和执行成本相容。本 skill 不写 stable，也不写关系、信念和他人模型。这些都属于硬约束，违反时拒绝所在的整组变化。

### 6.2 意图、行动与结果分离

行动选择不等于行动成功，预测后果不等于实际结果，意图不等于承诺。行动理由在行动发生前生成；反馈到来后，只能在新阶段更新预期、信念、策略或关系，不能回头改写当时的理由和预期。

### 6.3 角色倾向与非决定性

人格、价值和角色基线影响敏感度、优先级、风险阈值和策略偏好，不直接决定固定行为。同一角色在不同资源、关系、受众和时间条件下可以选择不同策略。保留未选方案和切换条件，是为了让跨事件的选择保持连贯：既不能每一步都像重新随机抽取人格，也不能把稳定性误写成每次都采取同一个行动。资源不足造成的不行动，不能被解释为低能力、低责任或低道德。

### 6.4 目标与基线保护

core_goals、稳定价值、人格和角色身份，不能为了事后解释一次行动而被改写。短期受阻首先改变当前目标、情绪、信念或策略状态。

### 6.5 软异常

以下情况按软异常处理，结果保留并标记待复核：选择与角色的价值或策略偏好明显不符，又找不到情境、代价或防御上的解释；切换条件已经出现而计划多轮不变；没有新证据却频繁切换策略；承诺的范围明显超出角色的履行能力，又找不到可解释的角色倾向。重大事件可以豁免事先声明允许的软边界，但必须说明依据；硬约束不可豁免。

### 6.6 回放一致性

之后的反馈、对方真实动机的揭晓或行动结果，都不能回头改写本阶段的候选集、理由、预期和承诺判断。使用受限随机时保留抽样原因和候选权重，避免把不可解释的随机翻转误认为人格变化。新证据只能在新阶段触发修订，旧计划标为已被取代并保留。

## 7. 最小示例

### 7.1 输入

接事件建模skill的示例。

周四早上，林晓的情境解释已经提交：“周凯没有按约定交付”是事实，“他今天下午能交”是中等确信的预测；他心假设有三个，可能性最大的是周凯遇到了数据或资源阻碍，较小的是他把任务排在了别的事情后面，另有一个二阶假设，周凯以为她会像上次一样通融；判断状态为保留多个假设，信息需求是问清延迟原因、看下午是否兑现，行动线索有私下询问、确认交付时间、预备调整汇总计划和暂不公开催促。她此刻轻度烦躁。

林晓是组长，可以分派和催办任务，但没有处分权。她当前的目标是周五前向主管提交汇总，这个目标服务于她“把小组带成能稳定交付的团队”的核心目标。她尽责性较高，预防焦点较强，认知闭合需要偏高；在价值上，她把可靠履责放在较高位置，同时重视对组员的关照。她对周凯的信任较高，此前没有针对这件事的计划。

### 7.2 处理

决策框架是：服务周五提交汇总的目标，受影响的是周凯、她自己和主管，时间范围覆盖今天、周五和小组的长期合作；群消息全组可见，私下沟通只有两人可见；私下询问可以撤回，公开催促和向主管报告都难以收回。她把互动结构判断为信息不完全的重复合作。

她考虑了七个候选：在群里公开催促并要求中午前交；私下询问卡点并确认下午的具体时间；私下询问同时问他是否需要帮忙协调数据；什么都不说等到下午；直接向主管报告延迟；自己接手整份报告；先按现有材料搭汇总框架，把周凯的部分留空。硬约束筛掉了“自己接手整份报告”，因为周五前她没有这么多时间。

后果评估中，公开催促可能加快进度，但会让周凯在全组面前丢面子；如果原因真是外部阻碍，这样做既不公平，也容易让冲突升级。直接报告主管眼下太早，会损害信任，也会让她在主管面前显得没有管住进度。等到下午成本最低，却放弃了信息，也压缩了周五前的缓冲。私下询问的信息价值最高，能区分前两个假设，关系代价低，也保留了之后加码的空间。

冲突在于可靠履责与关照组员之间。闭合需要推着她尽快拿出一个确定的处理，例如公开要求交付时间；但错误判断的代价，以及周凯以往可靠的记录，都支持先问清楚。预防焦点让她想要一个兜底方案。她的冲突姿态是合作。

### 7.3 输出

主行动是私下给周凯发消息：直接问卡在哪里，确认下午的具体交付时间，说明周五要交汇总，并问他是否需要她帮忙协调数据。表达上，她在简洁直接的基线上稍作缓和，给周凯留出解释的空间。备选计划是同时按现有材料搭汇总框架。切换条件有三条：如果周凯说明是外部数据的阻碍，就转为帮他协调数据方；如果下午没有交、也没有新的说明，就明确给出最晚时间，并说明对周五汇总的影响；如果到周四下班仍没有结果，再考虑提前告知主管可能的延迟。

她给自己定了一项承诺：周四下班前完成汇总框架，经 `commitment_update` 写入。问周凯是否需要帮忙只是询问，不是承诺；如果周凯接受，再形成相应的承诺。`goal_update` 在当前目标下增加“确认周凯报告的交付时间”这一子目标；`strategy_learning` 写入主策略、备选和切换条件；`memory_update` 标记了对上次延期经历的检索。她对周凯的信任不变。

观察信号是周凯的回复内容和下午是否交付，交给事件建模skill；选定行动、预期结果和自我承诺交给长期演化skill。

换一个角色，同样的情境可以有不同选择：规范导向很强、关系权重较低的组长，可能直接在群里重申期限；风险敏感高的组长，可能先向主管确认汇总期限能否宽限。三种选择都要说明保护了什么、牺牲了什么、承担了什么风险，以及在什么反馈下会改变。

### 7.4 反例

如果林晓把“周凯不重视这项任务”当作事实，在群里公开批评，属于把候选假设当作行动依据；如果把“下午能拿到报告”写成她对主管的承诺，属于把预测写成承诺；如果她在本阶段直接下调对周凯的信任，属于越权写入关系。这三种情况都应被拒绝。如果下午报告顺利交来，她回头把早上的理由改成“我早就确定是资源问题”，属于违反回放一致性，同样应被拒绝。
