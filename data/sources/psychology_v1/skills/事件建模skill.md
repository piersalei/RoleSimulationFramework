## 0. 定位与边界

### 0.1 目标

角色面对可见社会线索时，先形成一个带不确定性的情境解释，再交给后续行动选择。这个解释要分开回答四个问题：发生了什么，这件事对我意味着什么，对方可能为什么这样做，还缺什么信息才能判断。

### 0.2 负责范围

本 skill 覆盖从可见线索到情境解释的全过程。它先划定本角色在当前事件和阶段中合法可用的证据，确定本次能调用的心理理论层级；再判断情境定义和规范意义，做初级与次级评价，进行归因与责任判断；在此基础上生成若干关于对方心理状态的假设，修订相关信念并校准信心，最后判断是否需要先追问、观察或暂缓判断。过程中产生的情绪、信念和他人推断变化，以候选状态变化的形式提交。

### 0.3 不负责范围

本 skill 不选择行动，不形成承诺，也不设定策略，这些归行动计划skill。它不根据行动结果更新关系、声誉、策略权重，也不巩固事件记忆，这些归长期演化skill。它不判定对方的真实动机，不对事件作道德裁决，也不触及任何 stable 字段。

### 0.4 与前后 skill 的接口

上游输入是场景系统按可见性过滤后的角色可见事件集，加上一阶段已提交的 dynamic、相关 memory，以及尚未解决的假设。下游方面，情境解释交给行动计划skill作为行动选择的依据；事件中具有关系意义或承诺意义的线索，交给长期演化skill，由它在获得行动反馈后判断是否写回。行动反馈、对方解释或第三方信息到达时，本 skill 在新的事件阶段再次运行，对已有解释做修订。

## 1. 触发条件

### 1.1 新线索触发

角色观察到新的社会线索时触发本 skill。社会线索包括他人的言语、动作、表情、沉默或回应延迟；帮助、拒绝、批评、请求、违约、兑现等具有关系意义的行为；群体的表态、排斥或联盟变化；制度通知、处罚或规则变化；以及资源得失、权力位置变化的可见信号。

### 1.2 新证据再触发

既有事件出现新证据时也会再次触发，包括对方的解释、第三方转述、结果核实，以及行动计划skill事先设定的观察信号出现。这时 skill 以修订方式运行：在保留原有判断的前提下调整假设和信心，不重写上一阶段的结论。

### 1.3 不触发的情形

角色不可见的事件不触发本 skill。纯粹的时间推进且没有新线索时，交给衰减与恢复过程处理。与角色目标、关系、规范和自我都无关、显著性又很低的环境变化，只登记为已注意或未注意的线索，不展开评价和推断。

## 2. 输入与读取来源

### 2.1 角色可见事件与上下文

输入是本角色在当前时刻能够观察、听到或合理推知的事件，包括发生者、时间、公开内容、在场者和证据可靠程度。对方的隐状态、系统日志、其他角色的私有信息，以及本角色不可见的事件，在进入任何心理推断之前被排除。场景的公开程度、受众、适用的制度规则和时间压力，作为情境上下文一并读入。

### 2.2 stable

身份与资源决定事件对角色的意义和角色的行动空间。社会角色和制度位置提供可援引的角色规范与权限，可观察资源影响次级评价中的可控性判断。

traits 中的各模块分别影响评价和推断的不同环节。
1. 主人格方案只改变对事件的敏感度、反应峰值和恢复倾向，不直接决定解释结果；
2. 成人依恋的焦虑与回避两轴影响角色对关系威胁的敏感性，以及对模糊回应的解释偏向；
3. 动力基线中的 BAS、BIS、FFFS 和调节焦点影响威胁与奖赏的权重；
4. 情感系统中的评价倾向、情绪识别和共情能力决定角色怎样把事件转成情绪；
5. 认知风格中的认知需求、闭合需要、模糊容忍和元认知校准，决定角色保留多少个假设、多快定论和信心是否与证据相称；
6. 人格功能中的现实检验和防御成熟度，限定角色的解释可以偏离证据到什么程度。

心理理论能力上限由 traits 中的 71 维社会心智能力向量派生，主要来自信念追踪与二阶归因相关的维度，即一阶错误信念推理、双向心智状态追踪、自他认知边界识别和二阶及多阶心智归因。年龄、学历或职位只能作为初始化证据之一。

values 中的价值优先级、道德推理和文化取向，影响角色对规范违背的敏感度和违背等级判断。core_goals 用于判断事件与长期目标的相关性。

### 2.3 dynamic

读取事件前已提交的六个状态域。
1. affect_state 中的情绪、唤醒、压力和威胁或奖赏激活，决定注意是否窄化、心理理论是否降级，以及评价朝哪个方向偏；
2. cognition_state 提供相关命题的已有信念及其置信度、当前注意焦点、已有归因、自我评价，以及对该对象已有的心理推断和未解决的假设；
3. goal_state 中的当前目标及其优先级是目标相关性判断的直接依据；
4. relation_state 提供对该对象的信任、亲近、依赖、承诺、权力差和伤害历史；它在本 skill 中只作为解释背景，不被修改；
5. group_state 中的成员资格、身份显著性和规范显著性影响规范意义判断，也影响对内外群体成员的解释偏差；
6. policy_state 中尚未完成的承诺和事先设定的观察信号，用于判断对方的行为是否构成兑现、违约或延误。

### 2.4 memory、thought 与 mechanism_log

memory 按当前线索检索与该对象相关的承诺与违约、伤害与修复、峰值事件和相似情境。检索结果要区分三层：事件曾经发生、角色此刻能回忆起来、角色认为它意味着什么。mechanism_log 提供上一阶段的评价、假设和尚待获取的区分性信息，用于修订，也用于识别评价固着。thought 是模型的原始输出，不作为证据。

### 2.5 读取快照与优先级

同一角色、同一事件、同一阶段只读取同一份已提交快照。本 skill 内部各步骤之间可以传递中间判断，但这些判断始终是候选，不是已生效的状态。

证据的可信程度依次为直接观察、可信第三方转述、一般转述与传闻、角色自身推断；系统掌握的真实信息不进入这个序列。涉及特定对象时，对象特异的关系史优先于全局依恋基线。某个模块处于未知、关闭或未建模状态时，跳过依赖它的推理分支，并记为信息不足，不用默认值冒充观测。

## 3. 处理流程

### 3.1 建立证据集

先按可见性排除不可用信息，再由注意机制决定哪些可见线索进入加工。威胁、损失、突然变化和强烈情绪会自下而上抢占注意，当前目标、价值和角色责任则自上而下提高相关线索的权重。随后检索相关记忆。没有进入注意的可见线索要单独保留并说明原因：它们没有消失，只是暂未被加工，之后可能经他人提醒或在后果出现后被重新检索。高能力可以减少遗漏，但不能补全角色没有获得的信息。

### 3.2 确定本次可用的心理理论层级

本次可用层级以 stable 中的能力上限为天花板。高负性唤醒、依恋威胁、羞耻、疲劳、时间压力、关键信息缺失或陌生任务领域，都可能让它临时下降，但它不能高于上限。一阶推断指根据可见行为推断对方的信念或意图，二阶推断指推断对方认为第三者（包括本角色）怎样想。降级的原因要随结果一并记录。

### 3.3 情境定义与规范意义

判断正在发生的是什么，例如正常的工作催促、玩笑、羞辱、试探或求助，并估计各方对情境的定义是否一致。同一个动作，一方定义为玩笑、另一方定义为羞辱，后续的情绪和规范判断会完全不同。

接着识别适用的规范，包括正式规则、组织惯例、礼仪和关系承诺，判断是否构成违背，以及违背属于失礼、越界、道德违背、制度违约还是法律违背。这一步只判断规范是否被违背，谁该负责留到 3.5。

### 3.4 初级与次级评价

初级评价判断事件与哪些当前目标或核心目标相关，目标一致还是不一致，属于收益、损失、威胁还是挑战，以及短期和长期影响。同一事件可以对不同目标同时是收益和损失，两者分开记录。

次级评价判断角色对局面有多少控制感，有哪些资源、支持和时间窗口，结果是否仍可改变。事件若涉及公开评价、角色身份或自我形象，还要评估身份与面子意义。评价会形成接近、回避、对抗、暂停、求助或谈判等方向上的倾向，这些倾向只作为行动线索向下传递，不在本 skill 中选定。

### 3.5 归因与责任判断

先区分结果、意图和背景证据，再沿内在与外在、稳定与暂时、全局与具体、可控与不可控四条轴判断原因；证据不足的轴保持未定，不强行填入。责任分为事实责任、道德责任、关系责任和制度责任，四者分别判断：意图良好不能抵消可预见的严重后果，结果严重也不自动证明恶意。对自己和对他人的归因分开记录，以便识别自利偏差之类的不对称。

### 3.6 生成他心假设

围绕对方的目标、信念、意图、能力、限制条件或情绪，生成一到三个假设。每个假设都要写明支持证据和反向证据、角色对它的信心、有哪些替代解释，以及什么新信息能把它与其他假设区分开。假设的阶数不能超过 3.2 确定的本次可用层级。互相排斥的假设与可以并存的假设要区分。

这一步同时记录角色当前的心智化方式：自动、反思、过度心智化、心智化不足，或者暂停判断。偏差按决策机制库的 1.11 的组合规则记录，只写一个主导加工模式、被它放大的偏差和一个最主要的校正机会，不把多种偏差叠加成无法解释的全错状态。事件构成自我威胁时，可以记录投射、否认等防御作为解释偏差的来源，但所用防御必须与角色的现实检验水平和防御成熟度相称。对方的信任与声誉在这里只作为解释背景，它们是否变化由下游判断。

### 3.7 信念修订与信心校准

事实命题（他没有按时交付）和解释命题（他不重视这项任务）分开建模、分开更新，关于他人心理的解释归入他人模型。置信度表示角色对某个具体命题为真的主观确信；尚未形成判断就记为未知，不以中间值代替。新信念与旧信念冲突时，可以并存待证、按情境分化、降低确信或悬置，不覆盖历史。最后检查信心是否与证据强度相称；不相称的部分必须能由角色的闭合需要、确认性加工、依恋取向或关系史解释。

### 3.8 信息需求与行动线索

综合错误判断的代价、行动的可逆性、时间压力和关系风险，判断角色是否需要先追问、观察、核验、寻求第三方信息或暂缓判断，并写明要获取什么信息、向谁获取、用来区分哪些假设。闭合需要高的角色倾向于过早定论，闭合需要低而错误代价高的角色可能长期不行动，两种倾向都要能从角色设定中找到依据。“尚未判断”是有效输出，不能为了得到完整印象而强行收口。

### 3.9 形成情境解释与候选变化

把以上结果整合为交给下游的情境解释，由相应更新算子生成候选状态变化，并写入机制日志。

## 4. 调用机制与更新算子

### 4.1 决策机制

本 skill 调用的机制来自决策机制库的四个部分。信息加工部分提供注意分配与信息过滤（1.1）、记忆检索（1.2）、双过程加工（1.3）、不确定性与闭合需要（1.5）、启发式与系统性偏差（1.6）、信念更新与确认性加工（1.7）、归因与责任判断（1.8）、元认知监控与信心校准（1.9）。事件评价部分提供初级与次级评价（2.1）、威胁与奖赏反应政策（2.2），防御机制（2.5）作为解释偏差的来源。社会交互部分提供社会信息加工序列（3.1）、心智化执行模式（3.2）、印象形成与刻板化（3.3）、信任与声誉更新（3.4），其中 3.4 在本 skill 中只读取既有信任作为解释偏向。社会结构部分提供情境定义（9.9）和规范识别与违背判定（9.11）。

机制之间的组合遵循决策 1.11、2.7、3.6 的组合规则：先编码和解释社会线索，再做心智化与归因，最后由评价机制处理威胁与资源意义。刻板类别、单次结果或未经核验的心智推断，都不能直接覆盖个体化信息。所有机制只产生中间判断、候选解释和未选原因，没有状态写权限。

### 4.2 更新算子

本 skill 的核心写回由三个算子完成。`emotion_update` 写入评价产生的情绪标签、效价、唤醒、强度和威胁或奖赏激活；本阶段若发生了情绪调节，调节结果也经它写回。`belief_revision` 写入事实命题信念及其置信度，以及归因与责任判断。`other_model_update` 写入对他人目标、信念、意图和能力的假设及其置信度，这些假设允许是错的，但必须保留证据。

事件涉及面子、羞耻、责任评价或当前任务自我效能时，追加调用 `self_state_update`；事件激活了规范显著性或身份显著性时，追加调用 `group_state_update`。

本 skill 不调用关系、目标、承诺、策略、记忆巩固和衰减相关的算子。目标相关性以评价结果的形式交给行动计划skill，关系与承诺意义以信号的形式交给长期演化skill。这样做是为了防止一次带有不确定性的推断直接改写信任或关系状态。

### 4.3 执行顺序、候选 StateDelta 与提交

逻辑顺序为可见性划定、注意与记忆、情境定义与评价、归因与心智化、信念修订与校准、信息需求。这是保证可复现的计算顺序，不意味着心理过程是线性流水线；新的线索可以在任何节点重新触发评价，但要开启新的事件阶段，不能覆盖本阶段的结果。

所有候选变化都以同一份事件前快照为前提。变化幅度要与事件严重度、证据强度和角色敏感度相称；人格对幅度的调节作用在敏感度、峰值、持续时间或恢复速度上，不直接放大变化量。

### 4.4 mechanism_log 记录

日志需要让一次解释能够从结果回溯到证据。它应记录：角色此次纳入和未纳入的证据，被排除的不可见信息；心理理论能力上限、本次可用层级和降级原因；情境定义、规范判断、评价和归因的中间结果；全部假设，包括被放弃的假设及放弃原因；主导加工模式、被放大的偏差和校正机会；以及候选与最终状态变化、被拒绝的项目和异常标记。

## 5. 输出与接口

### 5.1 情境解释

输出一个情境解释，内容包括角色采信的证据和未注意到的线索、本次可用的心理理论层级、情境定义与规范违背判断、初级与次级评价结果、归因与责任判断、带置信度和替代解释的他心假设集合、当前的判断状态（已定论、保留多个假设或暂缓判断）、信息需求，以及由评价倾向导出的可行行动线索。情境解释中的推断都保持候选身份，下游不能把可能性最高的假设当作事实。

### 5.2 状态变化候选

候选状态变化包括情绪与威胁或奖赏激活的变化、事实信念与归因判断的变化、他人模型的变化，以及在相应条件下的自我状态与群体状态变化。每条候选变化都要引用角色可见的证据，说明调用了哪些决策机制，经哪个更新算子写回。

### 5.3 交给下一阶段的内容与条件

行动计划skill在本阶段的候选变化完成校验提交后，读取最新已提交状态和情境解释，重点使用评价结果、他心假设、判断状态、信息需求和行动线索。

事件含有关系意义、承诺兑现或违约、伤害线索时，相应信号连同证据和所依赖的假设一起交给长期演化skill；后者在获得行动反馈、对方解释或时间证据后，再决定关系、承诺和记忆是否更新。

判断状态为保留多个假设或暂缓判断时，未解决的假设和区分性信息留给本 skill 的下一阶段，作为修订的起点。

## 6. 约束与异常处理

### 6.1 证据与能力边界

角色只能使用自己可见的信息，推断不能引用被排除的内容，也不能把自己的推断当作观察到的证据。推断阶数不能超过本次可用层级，本次可用层级不能超过能力上限。本 skill 不写 stable，也不写无权限的关系、目标和策略字段。这些都属于硬约束，违反时拒绝所在的整组变化。

### 6.2 事实、推断与预测分离

三者必须分开记录。证据不足时保留多个假设，不强行选定唯一动机；尚未判断时如实记为未判断。事件评价不等于道德裁决，角色可以先感到受损或威胁，之后再重新解释事件。

### 6.3 幅度相称

单次模糊事件不能造成大幅的情绪、信念或他人模型变化，更不能经由本 skill 直接改变信任、关系或核心目标。变化幅度落在典型区间外、置信度明显偏离证据强度且找不到角色偏差的解释、证据已经改变而评价多轮不变，这几类情况按软异常处理：结果保留，同时标记待复核。重大事件可以豁免事先声明允许的软边界，但必须说明依据；硬约束不可豁免。

### 6.4 错误推断的合理性

他心推断可以错，但错误必须与可见证据、角色偏差、能力上限和既有关系史相容。防御性解释必须与角色的现实检验和防御成熟度相称，不能把普通的警惕或真实存在的操纵病理化。诊断名称、国籍、性别、职业和外貌，都不能作为推断对方人格、能力或道德性的依据。

### 6.5 回放一致性

之后的关系恶化、对方真实动机的揭晓或行动结果，都不能回头改写本阶段的推断和信心。新证据只能在新的阶段触发修订，旧的假设标为已被取代并保留。

## 7. 最小示例

### 7.1 输入

组长林晓在上周例会上听到同事周凯答应周三下班前交数据报告。到周三下班时，她没有收到报告；周四早上，周凯在群里说“还在改，今天下午给”，没有说明原因。周凯曾私信另一位同事，抱怨某部门迟迟未给数据，这条信息对林晓不可见。

林晓尽责性较高，依恋大致安全，认知闭合需要偏高，心理理论能力足以支持二阶推断。她当前的目标是周五前向主管提交汇总，对周凯的信任较高。在她的记忆里，周凯以往基本按时交付，两个月前延期过一次，事后说明了原因，她当时接受了。

### 7.2 处理

那条私信被排除在证据之外。林晓注意到承诺、未交付和群消息三条线索，并回忆起周凯过去的可靠记录和上次被接受的延期。她此时时间压力中等、情绪平稳，可以使用二阶推断。她把局面定义为工作交付延迟，属于轻度的工作承诺违背。在评价上，这件事威胁到她周五前提交汇总的目标，但她仍有追问和调整计划的余地；如果主管问起，还会牵涉她在主管面前的面子。归因方面，责任在事实上属于周凯，但原因是否出在他本人身上、是否在他控制之内，现有证据都还无法判断。

她形成三个假设：可能性最大的是周凯遇到了数据或资源上的阻碍，依据是他一贯可靠且主动给出了新的时间；可能性较小的是周凯把这项任务排在了别的事情后面，依据是他没有提前告知延期；还有一个二阶假设，周凯以为她会像上次一样通融。前两个假设互相排斥，第三个可以和它们并存。闭合需要让她有尽快定论的倾向，主要校正机会是私下问清卡点。

### 7.3 输出

林晓的情境解释保留多个假设，没有定论。“周凯没有按约定交付”被确认为事实；“他今天下午能交”只是中等确信的预测；三个假设连同各自的证据和区分条件一起进入他人模型。她的情绪从平静转为轻度烦躁。这份解释提示两项信息需求，一是问清延迟的具体原因，二是看下午是否兑现；可行的行动线索有私下询问、确认交付时间、预备调整汇总计划，以及暂不公开催促。这些都交给行动计划skill。

可靠性方面的负向线索和承诺延误的线索交给长期演化skill，本 skill 不改变林晓对周凯的信任。

### 7.4 反例

如果林晓引用那条私信，直接认定周凯“不负责”，属于越过证据边界并在模糊事件下强行定论；如果她在下午得知真实原因后，回头改写此时的判断，属于违反回放一致性。这两种情况都应被拒绝。
