## 0. 总括

三个 skill 不是三个互相独立的“人格模块”，而是一个从事件理解到行动，再到跨事件状态演化的最小闭环。它们分别回答三个不同问题：

1. **社会评价与他心推断**：角色认为发生了什么、对方可能想什么？
2. **多目标、多约束行动选择**：在当前信息、能力、资源和时间范围内，角色现在准备怎么做？
3. **跨事件学习、适应与状态演化**：这次经历会留下什么，怎样影响下一次行动，是否足以改变角色的长期基线？

三者必须区分“观察到的事实”“对事实的解释”“准备采取的行动”“行动实际造成的结果”和“结果带来的状态更新”。不能用后一步的状态变化反过来证明前一步的推断，也不能用一次行动直接改写稳定角色设定。

---

## 1. 社会事件评价与他人推断

这是角色面对可见社会线索后的事件建模 skill，为后续行动选择提供带有不确定性的情境解释。

- **触发**：观察到新言语、动作、表情、违约、帮助、拒绝、沉默、群体反应、制度反馈或其他模糊社会线索；既有事件出现新证据时也可再次触发。
- **读取**：角色当前可见的事件和参与者、相关记忆、注意焦点、当前目标、情绪和压力、关系与群体状态、能力与资源、角色规范、ToM 能力上限与本次可用层级，以及上一阶段尚未解决的假设。
- **过程**：
  1. 建立本角色在当前事件和阶段中可见的证据集，区分直接观察、他人转述和系统不可见信息；
  2. 对事件做初步评价：目标相关性、奖赏/威胁、责任归属、可控性、规范意义、身份和面子意义、短期与长期影响；
  3. 区分“发生了什么”“这意味着什么”和“对方可能为什么这样做”；
  4. 生成 1—3 个关于对方目标、信念、意图、能力或限制条件的假设，为每个假设记录证据、置信度、替代解释和需要什么新信息才能区分；
  5. 判断是否需要先追问、观察、验证、寻求第三方信息或暂缓判断；
  6. 输出给行动选择 skill 的情境模型，而不是直接把最可能的解释当作事实。
- **输出**：事件评价、他心假设集合、各假设置信度、注意/信息搜集建议、情绪与威胁/奖赏激活候选，以及允许进入下一阶段的可行行动线索。

例如，对方迟交任务时，角色可以根据已见信息推断“遇到资源困难”“重视程度不足”或“有意回避”，也可以先询问原因；但不能直接读取对方的真实动机，更不能因为后续关系恶化就把最初的不确定推断改写成确定事实。

## 2. 多目标、多约束行动选择与策略执行

这是把事件评价转化为行动计划的核心 skill。它处理的不是单纯的“目标—关系—规范”三者权衡，而是角色在**多重目标、身份与角色义务、价值和规范、资源与能力限制、风险、情绪、自我形象、群体位置、信息不确定性以及不同时间尺度**之间进行的行动选择。

- **触发**：出现两个或以上可行行动；当前目标、长期目标、角色义务、群体规范或关系利益发生冲突；行动具有风险、不可逆性、公开性或未来承诺后果；新信息要求改变原计划；或上一策略的切换条件被满足。
- **读取**：
  - `goals_now`、`core_goals`、`values`、身份与角色期待、角色承诺和自我评价；
  - 当前情绪、压力、自我效能、风险感知、能力、时间、金钱、信息和社会支持等资源；
  - `trust`、`closeness`、`dependence`、`commitment`、权力差、群体成员资格、规范显著性、声誉和未完成承诺；
  - 已有策略、主策略与备用策略、切换条件、过去结果和相关记忆；
  - 对他人反应的预测、行动的可逆性、执行成本、被观察者和受众，以及事件的即时、阶段性和长期时间范围。
- **过程**：
  1. **确定决策框架**：明确当前行动服务的目标、受影响的对象、时间范围、公开程度、可逆性和不可接受的风险；
  2. **生成候选行动或行动序列**：至少考虑直接行动、澄清/搜集信息、合作/求助、有限试探、拒绝或设边界、等待/降温、转交第三方、退出等不同类型；候选项要写明对象、时机、表达方式、投入资源和预期后果；
  3. **先过硬约束**：安全、法律/制度、能力、资源、角色权限、明确承诺和不可逾越的个人边界；不具备执行条件的方案不能只靠高动机被选中；
  4. **评估多维后果**：分别估计目标进展、关系与依赖、群体规范和声誉、身份/自我一致性、情绪与面子代价、资源和执行成本、信息价值、未来选择空间、升级或失控风险，以及对下一事件的影响；
  5. **处理冲突与不确定性**：根据角色的价值优先级、目标层级、风险阈值、时间折扣、关系阶段和策略偏好进行比较；当信息不足时，信息搜集、低成本试探或暂缓本身可以是最优行动；
  6. **确定主行动和备选计划**：记录选择理由、放弃其他方案的主要代价、预期结果、观察指标和切换条件；区分“打算做什么”“已经做了什么”和“结果是否如预期”；
  7. **决定是否形成承诺**：只有明确向他人或自己承担未来行动义务，且写明内容、期限或验证条件时，才生成行动承诺；普通意图、当下选择和预测不能自动写成承诺；
  8. **输出行动**：向互动环境发送可执行的行动、言语行为或等待指令，并把决策依据和未选方案写入机制日志，供结果反馈和回放使用。
- **输出**：候选行动集、硬约束筛选结果、各方案的多维后果估计、主行动、备选行动、切换条件、预期与不确定性、是否形成承诺、需要等待的反馈，以及可以影响后续的策略状态候选变化。

例如，同样面对同事犯错，高依赖关系角色可能选择私下提醒，高规范导向角色可能选择公开纠正，高风险敏感角色可能先核实事实或寻求上级介入。三者都应能说明保护了什么、牺牲了什么、承担了什么风险，以及在什么反馈下会改变策略。

## 3. 跨事件学习、适应与关系、角色状态演化

这个 skill 负责把互动结果转化为能够影响未来行为的持久变化。它包括承诺履行与关系修复，但范围更大：还要处理记忆巩固、信念和自我评价变化、声誉与群体位置、策略学习、目标重排、角色承诺变化，以及在足够长或足够重大的轨迹中对角色基线目标、身份和发展状态的有限适应。

### 3.1 变化层级与时间尺度

| 层级     | 典型状态                                            | 常见触发                                | 时间特征                                              |
| ------ | ----------------------------------------------- | ----------------------------------- | ------------------------------------------------- |
| 事件层    | 情绪、注意、威胁/奖赏激活、当下目标                              | 单次事件或即时反馈                           | 快速变化，可衰减或恢复                                       |
| 关系/记忆层 | 信任、亲近、依赖、承诺、伤害历史、声誉、事件记忆                        | 有关系意义的行为、违约、修复和重复互动                 | 跨事件持续，受后续证据影响                                     |
| 策略/自我层 | 信念、自我效能、责任感、策略权重、切换阈值、对他人的预期                    | 结果反馈、成功/失败模式、他人评价、策略反复失效            | 中期积累，可迁移到相似情境                                     |
| 角色基线层  | `core_goals`、角色身份/角色承诺、价值显著性、长期发展取向、部分能力或人格表现基线 | 重复且一致的证据、重大转折、角色转换、长期资源和制度变化、明确自我重评 | 慢速、稀疏、带来源和版本；不能由一次普通事件直接触发；只能以修订候选形式提出，审核和版本迁移后生效 |

这里的“角色基线变化”不是把稳定设定任意改写，而是一个有门槛、有方向、有证据的长期适应过程。例如，连续多次照护责任与原有生活目标发生不可调和的冲突，可能使角色重新排序 `core_goals`；持续成功或失败可能改变自我效能和长期目标可行性；进入新职业或失去群体成员资格可能改变角色身份和规范显著性。关系中的一次争执、一次道歉或一次短期情绪波动通常只能改变动态状态，不能直接改变这些基线。

### 3.2 触发、输入与过程

- **触发**：形成、兑现、暂停或违约承诺；造成伤害、道歉、解释、补偿、边界侵犯或重复失信；重要目标达成或长期受阻；显著成功/失败；他人或群体的评价与排斥；角色转换、资源条件改变、制度变化、身份威胁；重复出现的互动模式；时间推移和恢复窗口；或角色明确进行自我重评和长期计划调整。
- **读取**：
  - stable 中的身份、社会角色、资源、人格/依恋和发展基线、`values`、`core_goals`；
  - dynamic 中的情绪、信念、目标、关系、群体和策略状态；
  - 相关事件记忆、反馈结果、承诺履行记录、伤害与修复历史、声誉和群体位置；
  - 事件的严重度、重复性、可控性、责任与意图、结果是否可验证、外部结构是否改变，以及角色是否能把结果归因于自己、他人或情境。
- **过程**：
  1. 判断本次结果属于短期激活、关系事件、策略学习、身份/角色变化还是可能的基线适应，并确定需要的证据强度和时间尺度；
  2. 巩固事件记忆，记录结果、责任、意义、置信度和未解决问题；区分“发生了坏结果”与“我因此形成了什么一般化信念”；
  3. 处理承诺和关系：判断伤害、违约、修复提议或修复结果，评价严重度、责任、意图、可控性、承认程度和重复性，在道歉、解释、补偿、重新协商、边界、暂缓信任、维持低强度关系或退出中选择；
  4. 更新关系、声誉、自我评价、信念、目标激活和策略权重；根据后续证据决定信任恢复、关系降级、策略切换和记忆再激活；
  5. 检查是否达到长期适应门槛：证据是否重复或足够重大，是否跨情境一致，是否改变了可用资源、角色位置或自我理解，是否有替代解释，角色是否有能力和动机整合这一变化；
  6. 若达到门槛，生成 **stable 修订候选**：可提议新增、删除、降级或重新排序 `core_goals`，调整角色身份、价值优先级或发展取向，并记录变更前后、证据、有效时间、置信度、可逆性和影响范围。候选在审核和版本迁移前不生效，本轨迹内的影响只通过 dynamic 体现：`goal_state` 中的目标激活、动态承诺和可行性，`cognition_state` 中的信念和自我评价，`policy_state` 中的策略权重，以及 `group_state` 中的身份显著性。若未达到门槛，只更新动态目标、策略、信念、关系或记忆；
  7. 生成面向未来的计划：新的子目标、修复/验证条件、备用策略、恢复路径和下一次应观察的证据；把长期变化传播到后续决策，但不让一次更新在同一事件内无限级联。
- **输出**：持久事件记忆、关系和承诺变化、信念/自我评价变化、声誉和群体状态变化、策略学习结果、`goals_now` 重排、stable 修订候选（待审核，不直接生效）、恢复/修复条件，以及下一阶段可读取的状态版本。

## 4. 三个 skill 的接口边界与完整循环

同一事件建议按“阶段快照”运行，避免一个阶段读取到尚未提交的候选状态：

```text
角色可见事件集
  → 社会评价与他心推断
  → 候选行动与多目标权衡
  → 行动/言语行为/等待
  → 环境与他人反馈
  → 结果归因、关系/记忆/策略更新
  → 必要时提出 stable 修订候选（不在本轮生效）
  → 下一事件读取最新已提交的 dynamic 和当前 stable 版本
```

- **Skill 1 的边界**：输出带置信度的事件解释和他心假设，不替角色决定真实动机，不直接完成关系修复或基线改写。
- **Skill 2 的边界**：输出当下行动计划和可选承诺，不把行动意图当成行动结果，不通过事后结果重写当时理由。
- **Skill 3 的边界**：只在获得行动反馈或时间证据后提交持久状态更新；关系修复只是其中一类，长期目标、角色身份、策略和自我模型的适应也必须纳入。dynamic 变化经更新算子提交；stable 层面的适应只输出修订候选，不直接写回。
