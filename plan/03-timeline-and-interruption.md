# 时间轴与打断：设计说明

2026-10-20。对应会议第 8 条："是否引入时间轴？控制角色打断，怎么模拟得更真实是个值得研究的问题。"

**状态：只有设计，没有实现。** 和环境组的接口合同 v0 已经对接完成，这一版不改合同。本文分两部分：在 v0 合同内就能做的，以及将来要改合同才能做的（作为下一版合同的提案）。

## 1. 问题拆开看

"时间轴"和"打断"其实是三件事：

| 问题 | 例子 | 归谁管 |
|---|---|---|
| 时间流逝本身改变心理 | 等了两小时没回音，紧张上升；隔一夜气消了 | 动力机制线（衰减、恢复规则） |
| 谁先说、谁插话、一句话能不能说完 | A 话说到一半被 B 打断 | 环境裁决（话轮调度） |
| 角色是否**想**打断、是否**忍得住** | 冲动性高的人更容易抢话 | 人格线（倾向）+ 环境裁决（是否成功） |

原则不变：**环境裁决发生了什么，角色只提出尝试**。打断是否成功、话说了多少，都应该由环境决定，再以事件回到角色。

## 2. v0 合同内能做的

不新增字段，只约定用法：

1. **时间推进 = 一条旁白事件。** 环境发出 `type=narration` 的事件，如"两小时过去了，对方没有回复"。这和心理学组的要求一致："时间推进须登记为可审计的时间事件，没有规则的字段不得默认衰减。"角色侧把它当普通可见事件处理，记忆会存下它。
2. **被打断 = 裁决结果 `partial`。** A 提交一段话，环境判定被 B 打断：
   - A 的 speech 事件只包含实际说出的前半句（环境截断 `content`）；
   - 给 A 的 `outcome` 用 `status=partial`，`detail` 写"话没说完就被打断"；
   - B 的插话作为一条新的 speech 事件，A 和 B 都可见。
   这些都是 v0 已有的类型和状态值。
3. **角色侧不用改。** 被打断的经历以事件进入记忆（`rolesim/memory.py`），下一轮决策能看到。是否因此更紧张、对对方印象变差，属于动力机制线，待心理学组给规则。

局限：v0 的 `turn` 是整数轮次，没有"说话时长"和"同时发生"的概念，打断只能由环境用脚本或规则硬性指定，角色无法表达"我想插话"。

## 3. 下一版合同的提案（需要和环境组再谈）

| 提案 | 字段 | 作用 |
|---|---|---|
| 事件时间戳 | `Event.time`（场景内时间，秒或 ISO 时间） | 区分"同一轮"和"隔了很久"；衰减规则可以按真实间隔计算 |
| 行动时长 | `ProposedAction.duration_hint` | 环境据此判断一句话说多久、能否被插入 |
| 插话意图 | `allowed_kinds` 增加 `interrupt`；或 `ProposedAction.urgency` | 角色能表达"我想现在就说"，由环境决定是否允许 |
| 半途感知 | 环境在角色说话途中调用 `perceive` | 角色可以根据对方反应中途收住或改口 |

调度方式上有两种选择，建议先做第一种：

- **离散事件调度**：环境维护一个按时间排序的事件队列，每个角色的行动带时长；有人提交 `interrupt` 时，环境比较优先级（谁先、谁更急、场景规范是否允许）决定是否切断当前发言。实现成本低，仍可完全审计。
- **连续 / 全双工**：每个角色持续"在听"，任意时刻可以开口。更接近真实对话，但需要流式模型和更复杂的裁决，暂不考虑。

## 4. 人格侧可以先准备的

不需要等合同，人格线可以先做：

- 一个 `interrupt-when-urgent` 类的 skill（插话倾向与克制），用 v0 下的 `wait` / `set_boundary` 等动作近似；等合同支持 `interrupt` 后再接上。
- 和心理学组确认哪些构念影响插话：冲动性（`neuroticism.impulsiveness`）、主张性（`extraversion.assertiveness`）、场景中的权力差和礼貌规范（决策库 6.2、9.4）。

## 5. 需要谁拍板

| 事项 | 谁 |
|---|---|
