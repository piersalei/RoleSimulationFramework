## 维护约定

- 新的计划或待定问题写在这里对应的文件里。
- 做完一项：把行为写进 `docs/`（通常是 docs/14 和相关说明），把验证写进 docs/15，再从这里删掉。不在 plan 里保留"已完成"的记录。
- 草案冻结后整份移入 `docs/`。
- 只有测试和审计能证明的事才算完成；"角色像不像人"没有被验证，不写成完成。
