# 计划与进度

这个文件夹记录**实现内容的过去、现在和将来**：做过什么、正在做什么、接下来要做什么，以及在等谁。
[docs/](../docs/) 则是框架本身的说明：设计、输入怎么写、运行流程、当前架构。两者的分工：

| | `docs/` | `plan/` |
|---|---|---|
| 回答 | 框架现在是什么、怎么用、怎么运转 | 为什么这样做、做了哪些、下一步做什么 |
| 随什么变 | 代码改了才改 | 每次规划、完成、调整都更新 |
| 例子 | 运行流程、架构、人物填写、评测方法 | 阶段记录、改动计划、待确认项、验证记录、未实现的设计 |

## 维护约定

- 完成一项就把它从"现在 / 将来"移到"过去"，并在对应详细文件里写验证结果。
- 计划文件里写"打算怎么做"和"待确认"；已经落地的行为描述要同步进 `docs/`，不要只留在这里。
- 只有测试和审计能证明的事才写"已完成"；"角色像不像人"没有被验证，不写成完成。
